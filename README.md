# FIFA World Cup Attendance & Weather Analysis

## Overview

This project analyzes whether weather conditions influenced FIFA World Cup attendance.

## Tools Used

- R
- ggplot2
- rvest

## Objectives

- Clean and integrate attendance and weather data
- Explore attendance trends
- Visualize climate differences
- Evaluate relationships using linear regression

## Key Findings

- Hot/sunny tournaments had the highest median attendance (~46,000).
- Variable-weather tournaments had lower median attendance (~39,000).
- Tournament start month was not a statistically significant predictor of attendance (p = 0.723, R² < 0.01).
